

# Day-18: Pomodoro Timer ⏳

A simple Python **Pomodoro Timer** from my #90DaysOfCode series.
Work in short, focused sessions with breaks in between — all from your console!

---

### Features

* Set custom work and break times
* Choose number of cycles
* Live countdown in the terminal
* Beginner-friendly, fully commented code

---

### How to Run

```bash
git clone https://github.com/shadowMomina/Day-18-Pomodoro-Timer.git
cd Day-18-Pomodoro-Timer
python pomodoro_timer.py
```

---

### Requirements

* Python 3.x
